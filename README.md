# Evaluación dimensional del Clúster B: Dinámica vincular y farmacología
**Ateneo de Psiquiatría**

Plataforma interactiva para el análisis dimensional psicopatológico (HiTOP / DSM-5 Sección III), reactividad frente al estrés interpersonal y psicofarmacología en trastornos de la personalidad del Clúster B.

## Estructura del Repositorio
- `app.py`: Aplicación interactiva desarrollada en Streamlit.
- `requirements.txt`: Dependencias del entorno (`streamlit`, `numpy`, `plotly`).
- `.gitignore`: Configuración de exclusiones de Git para Python.

## Ejecución local
```bash
pip install -r requirements.txt
streamlit run app.py
```
